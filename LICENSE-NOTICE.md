\# License Decision Pending



RELIQUARY is intended to become an open-source project, but the final license

has not yet been selected.



Until an explicit license is added to this repository, the source code,

schemas, documentation, diagrams, and other project materials remain subject

to normal copyright protections.



External contributors should not submit substantial code or documentation

until the maintainers publish the project license and contribution terms.



The current licensing plan is to evaluate:



\- an open-source software license for source code;

\- a documentation-friendly license for schemas, research material, diagrams,

&#x20; and project documentation; and

\- whether hardware design files require separate licensing terms.



This file is a project-status notice. It is not a software license and does not

grant permission to use, copy, modify, or redistribute the repository contents.



\## Decision criteria



The final license should:



\- permit legitimate security research and defensive use;

\- support open collaboration;

\- preserve attribution;

\- remain compatible with likely Rust and Xous dependencies;

\- avoid creating unnecessary barriers for medical-device security labs;

\- clearly separate software, documentation, and hardware licensing where

&#x20; appropriate; and

\- be selected before accepting substantial outside contributions.
